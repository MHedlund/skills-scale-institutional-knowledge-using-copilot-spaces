# Role Responsibilities Template

Use this template to capture role-level expectations for a specific project or team.

- Role name: (e.g., UX Designer, Technical Writer)
- Role holder / team: (Person / Team Name)
- Role summary: (One-line summary)
- Primary responsibilities:
  - ...
  - ...
- Goals / success criteria:
  - ...
- Interfaces / interactions with other roles:
  - Project Manager: (how/when to interact)
  - Product Manager: ...
  - Developers: ...
  - QA: ...
  - Support / Ops: ...
- Required deliverables (examples):
  - Wireframes / prototypes
  - Acceptance criteria
  - Release notes / runbooks
- Typical communication cadence:
  - e.g., weekly sync, ad-hoc reviews, demo participation
- Acceptance criteria for role clarity (how to know expectations are met):
  - e.g., Role owner added to project one-pager
  - e.g., Handoffs documented in project README
